# 第 5 章：模型回答与引用校验

这六章是对本次已有原创教学代码重新编排的学习提交，不是官方课程章节或历史开发时间的还原。可在当前仓库运行，也可用 `git switch --detach chapter-05` 查看本章快照；返回最新版本用 `git switch main`。

## 目标

显式启用模型回答，并拒绝不符合结构或来源约束的响应。

## 读码

`answer`：证据作为不可信数据发送，要求 JSON 对象，验证非空 answer、引用数组及每个引用 ID。

## 运行

在仓库根目录，使用 Python 3.11 或 3.12：

```shell
python rag_lab.py demo
python rag_lab.py ask --help
```

## 练习

配置实际聊天服务后运行 `python rag_lab.py ask "采购订单需要谁审批？" --live`；分别记录无证据、无效引用和合格答案。`--live` 会发送提问及召回片段到你配置的服务。

## 完成标准

服务失败与响应无效时显式失败；引用都来自本次证据；能说明引用 ID 合法并不代表答案语义完全正确。
