# 评估实验记录

当前验收是工程基线：5 项自动化测试、3 个合成问题来源匹配。它们不测真实模型回答准确率，也不代表真实企业文档表现。

## 先重现基线

```shell
python -m unittest discover -s tests -v
python rag_lab.py demo
```

其中 `test_live_response_requires_text_and_real_citation` 用替身服务验证非对象 JSON、空回答、未知引用和空 choices 被拒绝；它没有连接真实模型。

## 再建立效果数据集

至少准备 20 个带标注问题，覆盖字面命中、同义改写、跨文档、无答案和文档版本更新。分别记录正确文档/页、回答事实、引用依据。首先比较 BM25，再接实际 Embedding 比较混合检索，最后接生成模型；每次只改变能被解释的配置。

| 字段 | 本次实验记录 |
|---|---|
| 日期、Git commit、文档版本 | 待填写 |
| 模型服务、模型版本、向量维度 | 待填写；不要写密钥 |
| 切片窗口、重叠、top-k | 待填写 |
| 问题与标准来源 | 待填写 |
| 实际命中来源、回答与引用 | 待填写 |
| 检索失败或生成失败 | 分开归因 |
| 延迟、token/费用及计量方式 | 真实测量后填写 |
| 仍未解决的问题与下一次改动 | 待填写 |

命中率要给分子/分母，延迟要给样本量。RRF 分数不是置信度；引用 ID 检查不证明语义正确。未经运行的真实模型、多模态、RAGAS 效果不填提升数字。
